# Public research-log examples

This directory contains **synthetic, anonymized examples only**.

Never copy real files from the repository-root `research_logs/` directory into this
directory.

Real research logs may contain local paths, hashes, timestamps, derivation paths,
public blockchain addresses, backup structure and other metadata that should be
reviewed before any disclosure or publication.

The JSONL example in this directory uses invented values solely to document the
v0.3.0 research-log format.
